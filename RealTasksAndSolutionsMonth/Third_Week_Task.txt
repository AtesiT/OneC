 Кейс №3. Описание задания
Формы (картинки, видимость, условное оформление), команды, конструктор печати, внешняя обработка, БСП.
Справочник Студенты:
Добавить на форму элемента реквизит Фото (тип: ХранилищеЗначения или строка-путь, если не разбирали хранилище);
Добавить реквизит Статус оплаты (тип: Перечисление со значениями: Оплатил, Должник, Частично). Настроить условное оформление формы: если статус = Должник, то цвет текста красный, жирный, если же статус = Оплатил то цвет текста зеленый.
Документ Зачисление в группу:
В табличную часть добавить колонку с аватаркой студента (чтобы при подборе было видно лицо).
Добавить в шапку документа булевский реквизит Льготник. При установке этого флага автоматически обнулять цену (Стоимость = 0) во всех строках табличной части и делать поле Стоимость недоступным для редактирования.
Добавить на командную панель формы кнопку Очистить список (с диалогом подтверждения Вопрос()).
Создать макет для документа Зачисление в стиле Договор-оферта.
Вывести в макете: Шапку (Название школы, адрес), таблицу со списком студентов и стоимостью, итоговую сумму цифрами и прописью (воспользоваться общей функцией ЧислоПрописью или написать свою).
Подключить печатную форму через команду в форме документа.
Внешняя обработка. Установка цен курсов.
Создать внешнюю обработку для массового обновления цен в регистре ЦеныКурсов.
Основная форма обработки должна содержать табличную часть с колонками: Курс и Цена.
Необходимо реализовать множественный выбор курсов для этого на командной панели табличной части необходимо создать кнопку Подобрать при нажатии на которую открывается стандартный диалог выбора из справочника Курсы (тип: ВыбратьИзСправочника или через СтандартныйДиалогВыбора).
Пользователь должен иметь возможность выбрать несколько курсов, и они должны добавиться в табличную часть обработки (построчно).
Реализовать кнопку Установить цены, при нажатии на которую происходит проверка табличной части и если есть хотя бы одна строка с незаполненным полем Курс или Цена, то необходимо вывести сообщение с текстом: Ошибка в строке №N. Заполните все поля и прервать выполнение.
Если же проверка пройдена, то для каждой строки необходимо программно создать/обновить запись в регистре сведений ЦеныКурсов на текущую дату (или на дату, указанную отдельным реквизитом в шапке обработки). После успешной записи данных в регистр вывести сообщение: Цены успешно обновлены для N курсов.
Внедрение Библиотеки стандартных подсистем (БСП)
Необходимо внедрить БСП в нашу конфигурацию, чтобы использовать типовые механизмы. Необходимо подключить подсистему Контактная информация и привязать её к справочнику Студенты.
Необходимо настроить справочник Студенты для работы с контактной информацией:
В модуле менеджера справочника Студенты заполнить свойства (или в модуле объекта) для работы с БСП.
Добавить в реквизиты справочника стандартный реквизит КонтактнаяИнформация (тип: СправочникСсылка.КонтактнаяИнформация).
На форме элемента справочника Студенты разместить поле (или табличную часть) для отображения контактной информации (телефоны, email, адреса).
Использовать стандартный макет БСП для ввода контактной информации (чтобы было как в типовых конфигурациях: иконка Контакты и удобные поля).
Заполнить для проверки информацию у студентов.
